机器学习入门：随机森林分类任务

本教程面向编程和数学基础薄弱的读者，手把手教你使用随机森林 (Random Forest) 对鸢尾花数据集进行分类。我们会从安装包开始，一步步解释数据、模型参数、调参方法和结果评估。你只需跟着代码运行，就能学会随机森林的核心操作流程。

如果你完全没有代码基础，建议先完成 Python 入门：零基础编程速通指南 和 Pandas 简明教程 的学习再回到本教程。本文接续这两篇博客的内容展开讲解。

1. 包的安装

在运行代码前，需要先安装必要的 Python 库。如果你使用 Jupyter Notebook，可以在单元格中运行 !pip install 命令；如果在命令行，直接执行 pip install。

安装命令 (终端运行)

包名 作用
sklearn (scikit-learn) 机器学习工具库，包含随机森林、数据集、模型选择、评估指标等。
matplotlib 绘图库，用于可视化数据、预测结果和特征重要性。
pandas 数据处理库，用于读取、操作表格数据。
numpy 数值计算库，提供数组运算支持。
scipy 科学计算库，我们主要用它计算统计指标 (如相关系数) ，但分类任务中不常用，这里保留以备解释。

在本教程中，我们主要使用 sklearn 和 matplotlib。

2. 数据集的加载与划分

2.1 加载特征变量和目标变量

鸢尾花数据集是 sklearn 内置的经典分类数据集，包含 150 个样本，每个样本有 4 个特征 (即X，包括花萼长度、花萼宽度、花瓣长度、花瓣宽度四列变量) ，目标变量是 3 种鸢尾花的品种 (即y) 。

  • **X (特征) **：用于预测的输入变量，这里是花萼和花瓣的测量值。
  • **y (目标) **：我们要预测的输出变量，这里是花的类别 (0, 1, 2 分别对应三种花) 。

在机器学习中，我们总是用 X 去预测 y。

我们直接使用 sklearn.datasets.load_iris() 加载数据。

数据探索 (可视化)

由于是分类问题，我们可以查看不同特征下各类别的分布。例如，绘制花瓣长度和宽度的散点图，按类别着色。

2.2 划分训练集、验证集和测试集

我们需要将数据分成训练集和测试集。训练集用于训练模型，测试集用于评估模型在新数据上的表现。

关于验证集

  • 验证集 (Validation Set)：当我们调整模型超参数 (后续会详细介绍，比如随机森林的树的数量、最大深度等) 时，需要一组数据来评估不同参数组合的效果，这组数据就是验证集。通常我们会从训练集中再划分一部分作为验证集，或者使用交叉验证 (如 GridSearchCV 自动完成) 。
  • 什么时候不用：如果只是训练一个模型并评估最终性能，不需要调整超参数，那么只划分训练集和测试集就够了。但为了得到更好的模型，我们通常需要调参，因此会用交叉验证或验证集。

本例中，我们将使用 GridSearchCV 进行交叉验证，它自动将训练集划分为多个子集进行验证，因此我们不需要手动再划分验证集。

3. 随机森林的关键参数及调参方法

随机森林 (RandomForestClassifier，RF) 有很多参数，下面介绍几个最重要的。

3.1 基础概念讲解

在理解随机森林的参数前，必须先掌握几个核心机器学习概念。

3.1.1 过拟合 (Overfitting) 与欠拟合 (Underfitting)

  • 欠拟合：模型太简单，连训练数据都学不好，在训练集和测试集上表现都差。好比学生只背了公式却不理解，考试时题目稍有变化就做不出来。
  • 过拟合：模型太复杂，死记硬背了训练数据中的每个细节 (包括噪声)，在训练集上得分极高，但在新数据 (测试集) 上表现大幅下降。好比学生把课本例题答案全背下来，但遇到新题就懵了。
对比项 欠拟合 过拟合
训练集误差 高 极低 (接近 0)
测试集误差 高 (与训练集相近) 高 (远高于训练集)
原因 模型能力不足，特征太少或参数太简单 模型过于复杂，参数过多或训练太久
解决办法 增加特征、增加模型复杂度 (如增加树的深度) 简化模型、增加正则化 (如限制深度、增加叶节点样本数)、增加训练数据

随机森林通过集成多棵决策树，能有效减轻过拟合，但参数设置不当仍会出现上述问题。

3.1.2 决策树 (Decision Tree) 原理概述

决策树本质上就是一个 “是/否”的问答流程图。从树根开始问，根据答案走向不同分支，直到走到树叶 (最终结论)。

以鸢尾花数据集为例，一棵简化决策树的示意图：

这个图怎么看？

  1. 根节点 (第一个问题)：拿到一朵花，先量它的花瓣长度。如果 小于 2.45 cm，直接走向左边，判定为山鸢尾 (Setosa)。这个判断非常准，所以左边直接就是叶节点。

  2. 内部节点 当上一个问题无法确定分类时，再问一个问题：花瓣宽度 小于 1.75 cm吗？

  3. 叶节点 (最终结论)：叶节点里的样本越纯 (全是同一类花) 越好

    • 如果长度小于 2.45 cm，判定为山鸢尾 (Setosa)
    • 如果宽度小于 1.75 cm，判定为 杂色鸢尾 (Versicolour)。
    • 如果宽度大于等于 1.75 cm，判定为 维吉尼亚鸢尾 (Virginica)。

  4. 分裂：上图中的每一个“提问” 就是一次 分裂 (Split)，每一次分裂都会把数据一分为二。

不需要任何数学公式，只要回答两个问题，就能把三种花分开。这就是决策树的运行逻辑：不断地提问，不断地细分，直到分出类别。

📐 点击展开：决策树的正式定义与数学表达 (供有兴趣的读者查阅)

决策树：一种树形结构，每个内部节点表示一个特征上的测试 (如“花瓣长度 < 2.5 cm?”)，每个分支代表测试结果，每个叶节点代表一个类别 (或回归值)。构建时，算法递归地选择 最佳特征 和 最佳分裂阈值，使子节点的“纯度”最高 (常用基尼系数或信息增益衡量)。

数学定义 (分类树)：

假设训练集为 D，特征集为 A。若采用基尼系数 (Gini Index) 作为分裂准则，则当前节点的基尼系数计算公式为：

Gini(D) = 1 - ( p₁² + p₂² + … + p_K² )

其中，K 表示当前节点中类别总数，p_k 表示第 k 类样本在当前节点中所占的比例 (即该类样本数 ÷ 节点总样本数)。

决策树的构建过程，就是递归地遍历所有可能的特征和分裂点，计算分裂后的基尼系数下降值，选择下降幅度最大的那个特征和分裂点，作为当前节点的最优划分方案。

3.1.3 随机森林原理概述

随机森林就是种了很多棵决策树。既然一棵树容易“死记硬背” (过拟合)，那我们种几百棵不同的树，让它们一起投票，少数服从多数。

随机森林示意图 (以3棵树为例)：

随机森林的特征：

  1. 每棵树都不一样：随机森林在构建每棵树时，会随机抽取不同的训练样本 (有放回地抽，即 Bootstrap 自助采样) 和不同的特征。有的树只看花瓣，有的只看花萼，有的全看。这就保证了每棵树都有自己的“见解”。
  2. 投票定结果：当新数据进来，让所有树各自预测。上图中，树 1 和树 3 都认为是“山鸢尾”，树 2 认为是“杂色鸢尾”。
  3. 少数服从多数：“山鸢尾”得了 2 票，超过半数，所以随机森林最终就输出“山鸢尾”。

关于max_features参数：为了让每棵树长得不一样，随机森林不许每棵树看全部特征，这就是特征随机。max_features 这个参数就是用来控制“每棵树最多能看几个特征”的。它调得越小，树之间的差异越大，投票效果通常越好 (但也不能极端小，否则每棵树都太笨了)。

最终预测时，分类任务采用多数投票，回归任务采用平均值。当几百棵“片面”的树一起投票时，它们的错误会被相互抵消，最终得到一个既稳定又不容易过拟合的模型。

明白了上面这些逻辑，你就已经懂了随机森林的核心思想。接下来我们看有哪些参数可以调节这些树的“生长方式”。

3.2 关键参数及其含义

参数 含义 调大/调小的影响
n_estimators 森林中决策树的数量。 调大：模型更稳定，但训练和预测变慢，且可能过拟合 (如果太大) 。调小：训练快，但可能欠拟合。
max_depth 每棵树的最大深度。 调大：树更深，可以学习更复杂的模式，但容易过拟合。调小：防止过拟合，但可能欠拟合。
min_samples_leaf 叶节点最少需要的样本数。 调大：叶节点样本多，模型更平滑，防止过拟合。调小：模型更贴合训练数据，可能过拟合。
max_features 每次分裂时考虑的最大特征数。 调大：允许更多特征参与分裂，可能增加模型复杂度。调小：增加随机性，降低方差，但可能增加偏差。

还有其他参数如 min_samples_split 等，但以上几个最常用。

3.3 网格搜索 (GridSearchCV)

网格搜索是一种暴力搜索方法，我们给定每个参数的一组候选值，然后对所有组合进行交叉验证，选出得分最高的组合。

交叉验证 (Cross-Validation) 将训练集分成 k 份 (比如 5 折) ，每次用 k-1 份训练，1 份验证，轮换 k 次，最后取平均得分。这样可以更稳健地评估参数性能，避免偶然性。

K 折交叉验证示意图 (以 5 折为例)：

我们使用 GridSearchCV 自动完成这个过程。

注意：

  • n_jobs=-1 表示使用所有 CPU 核心加速计算。
  • 合适的参数可以让模型在训练集和测试集上都有好的表现，避免过拟合或欠拟合。通过网格搜索，我们可以自动找到相对最优的参数，而不必手动反复尝试。

4.2 分类评价指标

对于分类问题，我们不能用回归的 R² 或相关系数，而需要使用分类专用指标。我们以多分类为例 (鸢尾花有 3 类) 。

4.2.1 混淆矩阵 (Confusion Matrix)

一个表格，展示真实类别与预测类别的交叉计数。对角线是正确分类的样本，非对角线是错误分类。

混淆矩阵示意表 (以二分类为例)：

预测为正类 (Positive) 预测为负类 (Negative)
真实为正类 TP (真正例) FN (假负例)
真实为负类 FP (假正例) TN (真负例)
  • 对角线 (TP, TN) 是分类正确的样本。
  • 非对角线 (FP, FN) 是分类错误的样本。

对于多分类 (如鸢尾花有 3 类)，混淆矩阵是一个 3×3 的表格，行表示真实类别，列表示预测类别，对角线上的数字就是正确分类的样本数。例如，一个可能的结果示意表：

真实\预测 Setosa Versicolour Virginica
Setosa 10 0 0
Versicolour 0 9 1
Virginica 0 2 8

此表说明：Setosa 全部分对；Versicolour 有 1 个被误判为 Virginica；Virginica 有 2 个被误判为 Versicolour。

统计原理简释

这些指标都基于**混淆矩阵**的四个基本数 (二分类) ：
- TP (真正例) ：实际正，预测正
- TN (真负例) ：实际负，预测负
- FP (假正例) ：实际负，预测正 (I 类错误) 
- FN (假负例) ：实际正，预测负 (II 类错误)

4.2.2 评价指标

  1. **准确率 (Accuracy) **

    • 含义：预测正确的样本数占总样本数的比例。
    • 公式：准确率 = (TP + TN) / (TP + TN + FP + FN) (对于二分类，多分类为总体正确比例) 。
    • 适用：当各类别样本均衡时，准确率是很好的指标。
    • 局限：类别不平衡时，准确率可能虚高 (例如 95% 是 A 类，全预测为 A 也能有 95% 准确率) 。

  2. **精确率 (Precision) 和召回率 (Recall) **

    • 精确率：预测为正类的样本中，实际为正类的比例。公式：TP / (TP + FP)。它衡量“预测为正类的准确性”。
    • 召回率：实际为正类的样本中，被正确预测为正类的比例。公式：TP / (TP + FN)。它衡量“正类被找出的比例”。
    • 对于多分类，通常计算宏平均 (macro)或微平均 (micro)。

  3. F1-score

    • 精确率和召回率的调和平均数，综合两者。公式：F1 = 2 * (Precision * Recall) / (Precision + Recall)。适合不平衡数据集。

精确率和召回率分别关注 FP 和 FN，F1 是两者的平衡。在多分类中，我们可以将每个类别视为“正”，其他为“负”，然后计算平均。

4.3 在鸢尾花数据集上计算这些指标

4.4 结果解读

  • 准确率：假如我们得到 0.967，说明测试集上 96.7% 的样本被正确分类。
  • 精确率/召回率/F1：对于每个类别，报告这些值。如果某个类别的 F1 较低，说明模型在该类别上表现不佳。
  • 混淆矩阵：可以看到哪些类别容易被误分类。例如，如果 Virginica 被误判为 Versicolour 较多，说明这两个类别特征接近。

为什么这些指标重要？

  • 准确率直观，但不够全面。
  • 精确率和召回率能告诉我们模型在识别某一类时的错误类型。
  • F1 综合了二者，适合不平衡场景。
  • 混淆矩阵提供最详细的错误分布，帮助我们诊断模型弱点。

4.5 特征重要性

随机森林可以输出每个特征的重要性分数，帮助我们理解哪些特征对分类贡献最大。

特征重要性越高，说明该特征在决策树分裂中越常被使用，对分类越关键。这对特征选择和数据理解很有帮助。
