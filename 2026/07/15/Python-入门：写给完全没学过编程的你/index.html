Python 入门

Python 入门：写给完全没学过编程的你

本篇博客面向编程小白，目标只有一个：帮助大家快速开始写 Python 代码。在实践中学习，而不是被繁杂的语法和包绕晕，直接从入门到放弃。

无论你未来用 Python 做数据分析、网站后端，还是自动化脚本，有 7 个知识点是所有程序都绕不开的。本文就按这 7 大块，带你快速过一遍。不追求面面俱到，只讲最常用、最必须的部分，帮你快速建立编程思维。

1. 程序设计的基本结构

所有任务都可以解构为以下 顺序、条件、循环 三种基本结构。无论多么复杂的程序，归根结底都是由这三种结构组合而成的。下面我们逐一来看 Python 如何实现它们。

1.1 顺序结构

顺序结构就是代码从上往下逐行执行，没有跳转。这是所有程序的默认执行方式，也是另外两种结构 (条件和循环) 的“地基”——即使有分支和循环，代码的整体走向依然是顺序的，只是局部发生了跳转。

1.2 条件结构 (if / elif / else)

根据条件是否成立，决定执行哪段代码。语法上注意 冒号 和 缩进 (缩进后面会专门讲)。

多分支用 elif：

在条件结构中，Python 会从上到下依次判断每个条件，一旦某个条件成立，就会执行对应的代码块，并跳过后面所有的 elif 和 else。注意，else 不需要写任何条件，它表示所有条件都不满足时的默认情况。

1.3 循环结构 (for / while)

重复执行某段代码，直到条件不满足。

  • for 循环：常用于遍历序列 (如列表、字符串) 或固定次数。
  • while 循环：只要条件为真就继续，适合不知道具体次数的情况。

使用 while 时，务必记得在循环体内改变循环变量的值，否则会陷入死循环。

1.4 三元操作与列表推导式 (进阶)

1.4.1 三元操作 (if-else 简写)

三元操作是一种 简写的 if-else，适合在单行内根据条件赋不同值。

语法：值1 if 条件 else 值2 —— 条件成立取 值1，否则取 值2。

列表推导式 (循环 + 条件的组合简写)

三元操作不只用于单个值的判断，它还可以和循环结合，在一行代码内对列表中的所有元素进行批量处理。这种写法被称为 列表推导式。

举个场景：你有一个数字列表，想把所有偶数保留下来，过滤掉奇数。

新手须知：三元操作和列表推导式属于“进阶语法”，它们存在的意义是让代码更简洁、更高效——尤其是在处理大量数据时，列表推导式比手动 for 循环速度更快，因为它在底层经过了优化。但如果你是初学者，暂时不学它们也完全不影响你写程序。先用 if-else 和 for 循环把逻辑理清楚，等你写习惯了，自然会觉得这些简写用起来更顺手。到时候再回来翻这一节也来得及。

2. Python 的基础运算

2.1 数学运算符

运算符 含义 示例
+ 加 3 + 5
- 减 10 - 4
* 乘 2 * 6
/ 除 (浮点) 10 / 3 → 3.333…
// 整除 (取整) 10 // 3 → 3
% 取余 (模) 10 % 3 → 1
** 幂运算 2 ** 3 → 8

需要注意以下几点：

  • 加减乘 (+ - *) ：只要参与运算的任意一方是浮点数，结果就是浮点数。比如 3 + 2.0 得 5.0，4 * 1.5 得 6.0。

  • 除法 (/) ：结果永远是浮点数，即使两个整数相除能整除，结果也会带上小数位（如 4 / 2 得 2.0）。

  • 整除 (//) ：取整数部分，常用于取整操作。

  • 取余 (%) ：返回余数，最常见的用途是判断奇偶：num % 2 == 0 表示偶数，否则为奇数。

2.2 逻辑运算符

逻辑运算符用于组合多个条件，返回布尔值 True 或 False。

  • and (与) ：两边都为真才为真
  • or (或) ：至少一边为真即为真
  • not (非) ：取反

逻辑运算在条件判断中非常常用，比如在 if 或 while 中组合多个判断条件。

3. 代码打包 (函数与类)

当代码越来越多，我们需要打包起来复用，避免重复书写。

3.1 函数 (function)

简单来说，函数就是打包了一套数据处理流程。你不用关心它内部是怎么一步步处理的，只需要知道“给它什么，它会返回什么”就够了。这种把一段逻辑封装成一个独立单元、按流程执行的方式，通常被称为面向过程编程。

关于“面向过程”的简单理解：

面向过程的核心理念是：程序就是一系列操作步骤的集合，把数据丢进去，经过一步步处理，最后输出结果。函数就是用来组织这些步骤的基本单元。你写函数 A 处理第一步，函数 B 处理第二步，然后按顺序把它们串起来，整个程序就按照你设计的流程跑完了。初学阶段你大部分时间都在写这种风格的代码，它直观、好理解，非常适合从零开始建立编程思维。

3.2 类 (class)

如果说函数是把一段逻辑打包成一个可调用的名字，那么类就是把数据和操作这些数据的函数打包在一起。类里面定义的函数不叫函数，叫方法；类里面存储的数据不叫变量，叫属性。

由于类将操作对象 (数据) 和操作方法 (操作这些数据的函数) 捆绑在一起，这意味着类的设计是围绕着操作对象而展开的。这种打包方式，被称为面向对象编程。

4. 文件操作

4.1 文件的调用 (打开、读取、写入)

使用函数 open() 可以打开一个文件，它的第一个参数是文件路径，第二个参数是打开模式：

  • 'r' (read) ：读取模式，文件必须已经存在，否则报错。
  • 'w' (write) ：写入模式，文件不存在则自动创建，存在则会清空原有内容，相当于覆盖重写。
  • 'a' (append) ：追加模式，文件不存在则自动创建，写入的内容会添加到文件末尾，原有内容不会被覆盖。

此外，当文件包含中文时，建议指定 encoding="utf-8"，否则在不同系统上可能出现乱码。

需要留意的是，如果以 'w' 模式打开一个已有文件，它里面的旧内容会被清空。如果你只是想追加内容而不是覆盖，应该使用 'a' 模式。手动调用 close() 是为了告诉操作系统“这个文件我不用了”，释放它占用的资源。如果忘记调用，程序结束时系统虽然会自动回收，但在程序运行期间，文件可能一直被占用，导致其他程序无法操作它。

5. 代码规范性

写出能运行的代码只是第一步，写出好看、易读的代码同样重要。

5.1 缩进 (Indentation)

Python 用缩进表示代码块层级，不像其他语言用大括号。缩进必须一致 (一般用 4 个空格)。

大多数代码编辑器会自动将 Tab 转为空格，建议设置 Tab = 4 空格。

5.2 注释 (Comment)

注释是给人看的解释，Python 解释器会完全忽略它，不会影响程序的运行。

  • 单行注释：以 # 开头，用于解释单行代码或做简短说明。
  • 多行注释：用三个引号 ''' 或 """ 包裹，通常放在文件开头、函数或类的开头，用于写较长的说明。

注释应该写什么？

很多新手容易犯的毛病是注释“代码在做什么”，比如 i += 1 # i 加 1，这种注释毫无意义——代码本身已经说清楚了。好的注释应该解释为什么这么做，也就是代码背后的意图和思路。

一个简单而有效的注释习惯是：记录你的输入、输出和原理。换句话说，在你写一段逻辑之前，先用注释回答三个问题：

  • 这段代码的输入是什么？ (数据从哪里来、是什么格式)
  • 这段代码的输出是什么？ (期望得到什么结果)
  • 这段代码的核心思路是什么？ (实现逻辑)

这样做有几个好处：首先，写注释的过程会让你先把思路理清楚，而不是直接上手写代码然后在过程中把自己绕晕。其次，当代码量增多时，你能快速回想起当初的设计意图，而不需要从头读一遍每一行代码。在调用时也能快速上手。

函数的注释 (文档字符串)：

在定义函数时，可以在函数内部开头用三个引号写一段说明，这叫文档字符串 (docstring)。它和普通注释的区别在于，文档字符串可以通过 help() 函数被查看，方便其他使用者了解函数的用途。

在函数中写文档字符串是一个非常好的习惯，它让代码自带“说明书”，别人 (包括未来的你自己) 看这个函数时不需要去猜它是干嘛的。

最后一点：不必过度注释。好的代码本身应该是清晰、易读的，变量名取得好、逻辑分得清，很多地方根本不需要注释。把注释留给那些确实需要解释的复杂逻辑，它才能真正发挥价值。

6. 做一个“调包侠”

6.1 使用第三方库

Python 的一大魅力在于海量的第三方库。你不需要自己重新发明轮子，只需安装并导入别人写好的库，就能快速实现复杂功能。

常用库举例：

  • pandas：数据处理
  • numpy：科学计算
  • matplotlib：绘图
  • flask / django：Web 开发

初学时，先学会阅读库的官方文档，知道怎么调用函数、传递参数，比背下所有方法更重要。

7. print 调试法 (最简单的调试手段)

当程序运行结果与预期不符时，最直接的排查手段是在关键位置插入 print() 语句，包括：

  • 打印出关键变量的值，以便对照实际执行结果与预期是否一致。
  • 在程序分支的关键节点 (如条件判断处、循环进入/退出处) 插入 print()，用以跟踪程序的执行轨迹。

通过打印信息，你可以快速定位哪一步出了问题。虽然还有更高级的调试工具 (如 pdb、IDE 断点)，但对于入门者，print 足够应对 80% 的场景。
