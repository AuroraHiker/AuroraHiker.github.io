Python 入门：写给完全没学过编程的你

本篇博客面向编程小白，目标只有一个：帮助大家快速开始写 Python 代码。在实践中学习，而不是被繁杂的语法和包绕晕，直接从入门到放弃。

无论你未来用 Python 做数据分析、网站后端，还是自动化脚本，有 7 个知识点是所有程序都绕不开的。本文就按这 7 大块，带你快速过一遍。不追求面面俱到，只讲最常用、最必须的部分，帮你快速建立编程思维。

1. 程序设计的基本结构

所有任务都可以解构为以下 顺序、条件、循环 三种基本结构。无论多么复杂的程序，归根结底都是由这三种结构组合而成的。下面我们逐一来看 Python 如何实现它们。

1.1 顺序结构

就是代码从上往下逐行执行，没有跳转。这是最自然的方式。

1.2 条件结构（if / elif / else）

根据条件是否成立，决定执行哪段代码。语法上注意 冒号 和 缩进（缩进后面会专门讲）。

多分支用 elif：

1.3 循环结构（for / while）

重复执行某段代码，直到条件不满足。

  • for 循环：常用于遍历序列（如列表、字符串）或固定次数。
  • while 循环：只要条件为真就继续，适合不知道具体次数的情况。

小心死循环！记得在循环体内改变循环变量的值。

1.4 三元操作（条件表达式）

这是一种 简写的 if-else，适合在单行内根据条件赋不同值。

语法：值1 if 条件 else 值2 —— 条件成立取 值1，否则取 值2。

2. Python 的基础运算

程序离不开计算，Python 提供两类最常用的运算符。

2.1 数学运算符

运算符 含义 示例
+ 加 3 + 5
- 减 10 - 4
* 乘 2 * 6
/ 除（浮点） 10 / 3 → 3.333…
// 整除（取整） 10 // 3 → 3
% 取余（模） 10 % 3 → 1
** 幂运算 2 ** 3 → 8

注意：/ 结果永远是浮点数，// 和 % 常用于取整和判断奇偶。

2.2 逻辑运算符

用于组合多个布尔条件，返回 True 或 False。

  • and（与）：两边都为真才为真
  • or（或）：至少一边为真即为真
  • not（非）：取反

逻辑运算在条件判断中非常常用。

3. 代码打包（函数与类）

当代码越来越多，我们需要打包起来复用，避免重复书写。

3.1 函数（function）

函数是一段有名字的代码块，通过名字调用它，可以传入参数并返回结果。

函数让你把重复逻辑封装起来，提高代码可读性。

3.2 类（class）

类是更高级的打包方式，它将数据（属性）和操作（方法）捆绑在一起。初学者可以先了解概念，后续深入。

现阶段你只需知道：类是用来创建对象的模板，对象拥有自己的属性和行为。

4. 文件操作

程序经常需要读写外部文件（如 txt、csv）。

4.1 文件的调用（打开、读取、写入）

使用内置函数 open()，指定文件路径和模式（'r' 读取，'w' 写入，'a' 追加）。

4.2 Python 的自动关闭特性（with 语句）

手动 close() 容易忘记，Python 提供了 with 上下文管理器，在代码块结束后自动关闭文件，更安全简洁。

强烈建议：所有文件操作都用 with，省心又可靠。

5. 代码规范性

写出能运行的代码只是第一步，写出好看、易读的代码同样重要。

5.1 缩进（Indentation）

Python 用缩进表示代码块层级，不像其他语言用大括号。缩进必须一致（一般用 4 个空格）。

大多数代码编辑器会自动将 Tab 转为空格，建议设置 Tab = 4 空格。

5.2 注释（Comment）

注释是给人看的解释，Python 解释器会忽略它。

  • 单行注释：以 # 开头
  • 多行注释：用三个引号 ''' 或 """（通常用作文档字符串）

好的注释能帮助自己和他人理解代码意图，但不要注释显而易见的代码，注释应说明“为什么”而不是“是什么”。

6. 做一个“调包侠”

Python 的一大魅力在于海量的第三方库。你不需要自己重新发明轮子，只需安装并导入别人写好的库，就能快速实现复杂功能。

常用库举例：

  • pandas：数据处理
  • numpy：科学计算
  • matplotlib：绘图
  • flask / django：Web 开发

初学时，先学会阅读库的官方文档，知道怎么调用函数、传递参数，比背下所有方法更重要。

7. print 调试法（最简单的调试手段）

当你写的程序运行结果不符合预期时，最直接的排查方式就是在关键位置插入 print()，把变量的值打印出来，观察程序执行的轨迹。

通过打印信息，你可以快速定位哪一步出了问题。虽然还有更高级的调试工具（如 pdb、IDE 断点），但对于入门者，print 足够应对 80% 的场景。

结语

到这里，你已经浏览了 Python 的核心骨架：结构、运算、打包、文件、规范、调库和调试。这些内容能让你读懂入门代码，也能自己写点小工具。

接下来做什么？

  • 打开 Python，把文中示例挨个敲一遍
  • 不懂就 print() 看看中间结果
  • 想扩展功能，去 PyPI 找找库

编程不是看会的，是练会的。敲范例代码也好，写个小脚本也好，动手就对了。
