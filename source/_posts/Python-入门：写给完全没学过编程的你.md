# 1. 程序设计的基本结构

所有任务都可以解构为以下 **顺序、条件、循环** 三种基本结构。无论多么复杂的程序，归根结底都是由这三种结构组合而成的。下面我们逐一来看 Python 如何实现它们。

### 1.1 顺序结构

就是代码**从上往下逐行执行**，没有跳转。这是最自然的方式。

```python
print("第一步")
print("第二步")   # 先执行完上一行，才执行这一行
print("第三步")
```

### 1.2 条件结构（if / elif / else）

根据条件是否成立，决定执行哪段代码。语法上注意 **冒号** 和 **缩进**（缩进后面会专门讲）。

```python
age = 18
if age >= 18:
    print("已成年")
else:
    print("未成年")
```

多分支用 `elif`：

```python
score = 85
if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

### 1.3 循环结构（for / while）

重复执行某段代码，直到条件不满足。

- **`for` 循环**：常用于遍历序列（如列表、字符串）或固定次数。

```python
# 遍历列表
for fruit in ["苹果", "香蕉", "橘子"]:
    print(fruit)

# 重复 5 次（range(5) 生成 0~4）
for i in range(5):
    print(f"第 {i} 次循环")
```

- **`while` 循环**：只要条件为真就继续，适合不知道具体次数的情况。

```python
count = 0
while count < 3:
    print("循环中...")
    count += 1   # 一定要修改条件，否则死循环
```

> 小心死循环！记得在循环体内改变循环变量的值。

### 1.4 三元操作（条件表达式）

这是一种 **简写的 if-else**，适合在单行内根据条件赋不同值。

```python
age = 20
status = "成年" if age >= 18 else "未成年"
print(status)   # 输出：成年
```

语法：`值1 if 条件 else 值2` —— 条件成立取 `值1`，否则取 `值2`。

## 2. Python 的基础运算

程序离不开计算，Python 提供两类最常用的运算符。

### 2.1 数学运算符

| 运算符 | 含义       | 示例       |
|--------|------------|------------|
| `+`    | 加         | `3 + 5`    |
| `-`    | 减         | `10 - 4`   |
| `*`    | 乘         | `2 * 6`    |
| `/`    | 除（浮点） | `10 / 3` → 3.333... |
| `//`   | 整除（取整）| `10 // 3` → 3 |
| `%`    | 取余（模） | `10 % 3` → 1 |
| `**`   | 幂运算     | `2 ** 3` → 8 |

注意：`/` 结果永远是浮点数，`//` 和 `%` 常用于取整和判断奇偶。

### 2.2 逻辑运算符

用于组合多个布尔条件，返回 `True` 或 `False`。

- `and`（与）：两边都为真才为真
- `or`（或）：至少一边为真即为真
- `not`（非）：取反

```python
x = 5
print(x > 3 and x < 10)   # True
print(x > 10 or x < 3)    # False
print(not (x == 5))       # False
```

逻辑运算在条件判断中非常常用。

## 3. 代码打包（函数与类）

当代码越来越多，我们需要**打包**起来复用，避免重复书写。

### 3.1 函数（function）

函数是一段**有名字的代码块**，通过名字调用它，可以传入参数并返回结果。

```python
# 定义函数
def greet(name):
    return f"你好，{name}！"

# 调用函数
message = greet("小明")
print(message)   # 输出：你好，小明！
```

函数让你把重复逻辑封装起来，提高代码可读性。

### 3.2 类（class）

类是更高级的打包方式，它将**数据**（属性）和**操作**（方法）捆绑在一起。初学者可以先了解概念，后续深入。

```python
class Dog:
    def __init__(self, name):   # 初始化方法
        self.name = name

    def bark(self):
        print(f"{self.name} 在汪汪叫！")

my_dog = Dog("旺财")
my_dog.bark()   # 输出：旺财 在汪汪叫！
```

> 现阶段你只需知道：**类是用来创建对象的模板**，对象拥有自己的属性和行为。

## 4. 文件操作

程序经常需要读写外部文件（如 txt、csv）。

### 4.1 文件的调用（打开、读取、写入）

使用内置函数 `open()`，指定文件路径和模式（`'r'` 读取，`'w'` 写入，`'a'` 追加）。

```python
# 写入文件
file = open("test.txt", "w", encoding="utf-8")
file.write("Hello, Python!")
file.close()   # 记得关闭

# 读取文件
file = open("test.txt", "r", encoding="utf-8")
content = file.read()
print(content)   # 输出：Hello, Python!
file.close()
```

### 4.2 Python 的自动关闭特性（with 语句）

手动 `close()` 容易忘记，Python 提供了 **`with` 上下文管理器**，在代码块结束后**自动关闭**文件，更安全简洁。

```python
# 写入（自动关闭）
with open("test.txt", "w", encoding="utf-8") as f:
    f.write("自动关闭，放心！")

# 读取（自动关闭）
with open("test.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)
```

**强烈建议**：所有文件操作都用 `with`，省心又可靠。

## 5. 代码规范性

写出能运行的代码只是第一步，写出**好看、易读**的代码同样重要。

### 5.1 缩进（Indentation）

Python 用**缩进**表示代码块层级，不像其他语言用大括号。缩进必须**一致**（一般用 4 个空格）。

```python
# 正确缩进
if True:
    print("缩进 4 空格")
    print("同一层级")

# 错误示范（缩进不一致会报错）
# if True:
#   print("用了2空格")
#     print("又用了4空格")   # IndentationError
```

> 大多数代码编辑器会自动将 Tab 转为空格，建议设置 Tab = 4 空格。

### 5.2 注释（Comment）

注释是给**人**看的解释，Python 解释器会忽略它。

- **单行注释**：以 `#` 开头
- **多行注释**：用三个引号 `'''` 或 `"""`（通常用作文档字符串）

```python
# 这是单行注释，解释下面代码的作用
age = 18

"""
这是多行注释
可以写较长的说明
"""
```

好的注释能帮助自己和他人理解代码意图，但**不要注释显而易见的代码**，注释应说明“为什么”而不是“是什么”。

## 6. 做一个“调包侠”

Python 的一大魅力在于**海量的第三方库**。你不需要自己重新发明轮子，只需安装并导入别人写好的库，就能快速实现复杂功能。

```python
# 安装库（在终端执行）：pip install requests

# 使用库
import requests

response = requests.get("https://api.github.com")
print(response.status_code)   # 输出 200
```

常用库举例：
- **`pandas`**：数据处理
- **`numpy`**：科学计算
- **`matplotlib`**：绘图
- **`flask`** / **`django`**：Web 开发

初学时，**先学会阅读库的官方文档**，知道怎么调用函数、传递参数，比背下所有方法更重要。

## 7. print 调试法（最简单的调试手段）

当你写的程序运行结果不符合预期时，最直接的排查方式就是**在关键位置插入 `print()`**，把变量的值打印出来，观察程序执行的轨迹。

```python
def divide(a, b):
    print(f"a={a}, b={b}")   # 调试：看传入的参数
    result = a / b
    print(f"result={result}") # 调试：看计算结果
    return result

divide(10, 0)   # 你会看到 b=0，然后报错 ZeroDivisionError
```

通过打印信息，你可以快速定位哪一步出了问题。虽然还有更高级的调试工具（如 pdb、IDE 断点），但对于入门者，`print` 足够应对 80% 的场景。
