很多 Python 数据分析教程都会用到 Iris (鸢尾花) 数据集。它小巧、规整、字段含义直观，非常适合用来练习数据分析与可视化。

但不少初学者第一次运行下面这行代码时，就会遇到一个让人困惑的报错：

```python
import seaborn as sns

iris = sns.load_dataset("iris")
```

如果你遇到的是 `TimeoutError`、`URLError`、`HTTPError`，或者提示无法从网络获取数据，大概率是 **Seaborn 自动下载示例数据集时连接 GitHub 失败**。

这篇小博客专门记录这个问题的原因和两种稳妥的解决方式。以后在教程里遇到 `sns.load_dataset("iris")` 失败，可以直接照此排查。

---

## 1. Bug 成因：本地未缓存，联网拉取 GitHub 数据超时

`sns.load_dataset("iris")` 看起来像是在读取 Seaborn 自带的数据，实则在调用 Seaborn 提供的示例数据加载工具。

- 当本地已经缓存过 `iris.csv` 时，Seaborn 会直接从本地读取，代码顺利运行；
- 当本地还没有这个文件时，Seaborn 会尝试从官方数据仓库下载：  
  [Seaborn 官方数据仓库](https://github.com/mwaskom/seaborn-data/)

因此，报错通常由以下连续步骤引发：

1. 本地从未缓存过 `iris.csv` 文件；  
2. Seaborn 检测到缺失后，自动前往 GitHub 仓库在线拉取数据；  
3. 当前网络环境访问 GitHub 不稳定，导致下载请求超时。

总的来说，不是数据分析代码错了，而是示例数据集没有成功下载到本地。

---

## 2. 解决方案一：手动下载 `iris.csv` 并放入 Seaborn 缓存目录

既然自动下载常常受网络影响而失败，最直接的办法就是手动下载 `iris.csv`，并放入 Seaborn 的默认数据目录。此后运行 `sns.load_dataset("iris")` 时，Seaborn 会直接从本地读取，不再依赖网络。

### 2.1 找到 Seaborn 的数据存放目录

Windows 下默认路径通常是：

```text
C:\Users\你的用户名\seaborn-data
```

如果不确定自己的用户名，或者想让 Python 直接告诉你路径，可以运行：

```python
import seaborn as sns
print(sns.get_data_home())
```

如果这个文件夹不存在，可以手动创建。注意文件夹名称是 `seaborn-data`，中间有一个短横线。

### 2.2 下载 `iris.csv`

前往 [Seaborn 官方数据仓库](https://github.com/mwaskom/seaborn-data/)，找到 `iris.csv` 文件并下载即可。

如果 GitHub 访问不稳定，可以借助 **Watt Toolkit** 等工具来改善连接 (具体配置可参考 {% post_link Windows效率神器推荐-Wox-Markdown编辑器与GitHub加速器配置指南 %}) 。此外，出于交流学习的目的，本博客也提供了该数据集的直接下载链接：

> [iris.csv](/dataset/iris.csv)

下载完成后，建议检查以下几点：

- **文件名**：必须是 `iris.csv`，不要变成 `iris (1).csv` 或 `iris.csv.txt` (Windows 可能隐藏扩展名，请留意) ；
- **文件内容**：用记事本打开时，第一行应该是表头 (`sepal_length,sepal_width,...`) ，而不是 GitHub 网页的 HTML 内容；
- **存放位置**：`iris.csv` 应放在 `seaborn-data` 文件夹里，而不是放在你的 `.py` 文件旁边。

### 2.3 放入本地目录后重新运行

最终目录结构大致如下：

```text
C:\Users\你的用户名\seaborn-data\iris.csv
```

然后重新运行：

```python
import seaborn as sns

iris = sns.load_dataset("iris")
print(iris.head())
```

如果能看到类似下面的表格，就说明加载成功了：

| sepal_length | sepal_width | petal_length | petal_width | species |
|--------------|-------------|--------------|-------------|---------|
| 5.1          | 3.5         | 1.4          | 0.2         | setosa  |
| 4.9          | 3.0         | 1.4          | 0.2         | setosa  |
| 4.7          | 3.2         | 1.3          | 0.2         | setosa  |

### 2.4 故障排查清单

虽然 2.2 已提醒过，但如果放置后仍报错，不妨按下面几点逐一核对：

1. **路径是否正确**：运行 `print(sns.get_data_home())`，确认 `iris.csv` 就在打印出来的目录里。
2. **文件名是否正确**：尤其注意 Windows 隐藏扩展名的问题。
3. **文件内容是否正确**：打开文件检查：如果包含 <html> 标签，说明下载成了网页；如果文件为空，则说明下载未完成。两者都无法被 Pandas 正常读取，需要重新下载。

也可以用下面这段代码快速验证文件是否真的存在：

```python
from pathlib import Path
import seaborn as sns

iris_path = Path(sns.get_data_home()) / "iris.csv"
print(iris_path)
print(iris_path.exists())
```

如果第二行输出是 `True`，说明文件位置基本没问题；如果是 `False`，则表明文件没有放进 Seaborn 正在查找的目录，请回到第 1 步重新核对路径。

## 3. 解决方案二：直接使用 `sklearn.datasets.load_iris()`

如果只是为了学习绘图或机器学习，不一定非要使用 `sns.load_dataset("iris")`。`scikit-learn` 也内置了 Iris 数据集，而且不需要从 GitHub 下载，离线可用。

```python
import pandas as pd
from sklearn.datasets import load_iris

iris_raw = load_iris(as_frame=True)
iris = iris_raw.frame.copy()

# 将数值标签映射为物种名称
species_map = dict(enumerate(iris_raw.target_names))
iris["species"] = iris["target"].map(species_map)
iris = iris.drop(columns="target")

# 统一列名，与 Seaborn 版本保持一致
iris = iris.rename(columns={
    "sepal length (cm)": "sepal_length",
    "sepal width (cm)": "sepal_width",
    "petal length (cm)": "petal_length",
    "petal width (cm)": "petal_width"
})

print(iris.head())
```

这样得到的 `iris` DataFrame 与 Seaborn 示例数据的列名基本一致，后续绘图代码通常只需要很少修改 (甚至无需修改) 。
