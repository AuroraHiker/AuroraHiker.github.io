## 第 1 题 (基础排查与异常定位)

已知 `iris` 数据集实际只包含 **5 列**数据 (萼片长、萼片宽、花瓣长、花瓣宽、品种) 。如下方代码所示，该数据已被保存为 **制表符分隔 (.tsv)** 的文件。

> **要求**：请找出下列代码中的错误代码，并指明报错的具体原因。

```python
# 数据来源与保存 (读者无需修改此段)
import pandas as pd
import seaborn as sns
iris = sns.load_dataset('iris')
iris.to_csv('iris.tsv', sep='\t', index=False)  # 保存为 tsv
```

```python
# 代码段 A
df_custom = pd.read_csv(
    'iris.csv',
    names=['id', 'SL', 'SW', 'PL', 'PW', 'SP'],  # 为全部 6 列命名
    usecols=['id', 'SL', 'SP'],                  # 按新列名筛选 (此时 usecols 传入列表)
    index_col='id',                               # 将 'id' 列设为行索引 (可直接传列名)
    dtype={'SL': float, 'SP': str}
)
print(df_custom.head())
```

```python
# 代码段 B
df_custom = pd.read_csv(
    'iris.csv',
    usecols=[0, 1, 5],          # 先筛选出第 1 列 (id)、第 2 列 (sepal_length) 和第 6 列 (species)
    names=['id', 'SL', 'SP'],   # 为筛选出的三列依次命名 (必须与 usecols 的列数一致)
    index_col=0,                # 将第一列 (id) 设为行索引
    dtype={'SL': float, 'SP': str}   # 指定类型
)
print(df_custom.head())
```
